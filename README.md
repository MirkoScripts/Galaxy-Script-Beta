## ✨ Features

- 🌑 **Dark UI theme** with purple accent + smooth animations
- 🏠 **Home tab** — starter page with credits, changelog, and copy-link button
- 🚀 **Teleport tab** — create a locked `home` part at your position
- 🪟 **Floating mini tab** — small, draggable, with `Teleport`, `X` close and `-` minimize
- ⚡ **Speed Changer** — placeholder (coming in **v1.2 Beta**)
- 🎞️ **Animations everywhere** — window pop-in, tab fades, mini-tab slide, button pulses
- 🔐 **Locked home system** — home part unlocks on teleport, then re-locks after 1 second
- ⌨️ **RightShift hotkey** — quick show/hide of the main window
- 📋 **Copy GitHub link** button on the Home tab
